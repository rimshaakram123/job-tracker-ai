## 📖 Overview

Job Tracker with AI is a full-stack web application built to solve a real problem: **managing a job search is chaotic**. Applications, interviews, deadlines, resume versions, and notes get scattered across emails, spreadsheets, and sticky notes.

This platform centralizes everything into one clean dashboard and adds AI-powered intelligence to help you make better career decisions.

---

## ✨ Key Features

- 📋 **Application Tracking** — Log applications with company, role, status, and notes
- 📅 **Interview Management** — Schedule interviews and track follow-ups
- 🤖 **AI Resume Analysis** — Get instant feedback on your resume
- 🎯 **AI Job Matching** — Match your resume against job descriptions
- 💬 **AI Career Assistant** — Chat with an AI assistant for career advice
- 📄 **Resume Manager** — Upload and manage multiple resume versions
- 📊 **Analytics Dashboard** — Visualize your application pipeline
- 🔐 **Secure Authentication** — JWT-based login with password hashing
- 🛡️ **Protected Routes** — Role-based access control
- 📱 **Responsive UI** — Modern design that works on all devices

---

## 🛠️ Tech Stack

### Frontend
- **React 18** + **TypeScript**
- **Vite** for fast builds
- **React Router** for navigation
- **Context API** for auth state
- Modern CSS with responsive design

### Backend
- **Node.js** + **Express**
- **MongoDB** + **Mongoose** for data storage
- **JWT** for authentication
- **bcrypt** for password hashing
- **Multer** for file uploads

### AI Integration
- Resume parsing and analysis
- Job description matching
- Conversational career assistant
